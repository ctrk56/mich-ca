# Dental Clinic Website

A modern, professional website for a dental clinic with a clean and responsive design.

## 🦷 Overview

This website provides a complete online presence for a dental clinic, featuring:
- Attractive hero section with call-to-action
- Comprehensive services showcase
- About section highlighting clinic features
- Full contact information with Google Maps integration
- Responsive design for all devices

## 🚀 Features

### Design
- Modern, clean interface with blue gradient color scheme
- Smooth scrolling navigation
- Hover effects and animations
- Mobile-responsive layout

### Sections
1. **Navigation Bar** - Fixed header with navigation links
2. **Hero Section** - Eye-catching introduction with "Book an Appointment" CTA
3. **About Section** - Clinic information with key features:
   - Experienced Team
   - Modern Equipment
   - Comfortable Environment
   - Affordable Pricing
4. **Services Section** - Six service cards:
   - General Dentistry
   - Cosmetic Dentistry
   - Restorative Dentistry
   - Pediatric Dentistry
   - Orthodontics
   - Emergency Care
5. **Contact Section** - Complete contact information:
   - Google Maps location link
   - Phone number
   - Business hours
   - Email address
   - Contact form
6. **Footer** - Copyright information

## 📁 Files

- `index.html` - Main HTML structure
- `styles.css` - Complete styling and responsive design

## 🌐 Viewing the Website

### Option 1: Open Directly
Simply open `index.html` in any modern web browser.

### Option 2: Local Server
For the best experience, run a local web server:

```bash
cd dental-clinic
python3 -m http.server 8000
```

Then visit: `http://localhost:8000/index.html`

## 📝 Customization

To customize the website for your specific clinic:

1. **Update Contact Information** in `index.html`:
   - Phone number
   - Email address
   - Business hours
   - Clinic name

2. **Modify Colors** in `styles.css`:
   - Search for color codes and update to your brand colors

3. **Add Real Content**:
   - Replace placeholder text with actual clinic information
   - Add real images
   - Update service descriptions
